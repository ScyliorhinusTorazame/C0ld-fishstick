# 私密文件传输工具（SFTA v2）

在浏览器本地把图片 / 视频打包加密成**一个** `.sft` 文件，对方在自己的浏览器里解密查看。
**数据不经过任何服务器**，没有账号、没有上传、没有 CDN 依赖。

## 怎么用

页面顶部是一条**密钥条**（点开才展开输入），底部是**发送 / 接收**两个 Tab，主按钮固定在拇指区，不用滚动去找。默认**深色**，右上角按钮一键切浅色。

### 发送方
1. 点顶部密钥条 → 点 **生成** → 点 **复制**，通过另一条渠道（语音/短信/当面）把密钥发给对方。
2. 「发送」Tab → 选择图片（可多选）或视频 → 点底部 **加密并下载 .sft**。
3. 把生成的 `.sft` 发出去。**必须用微信/QQ 的「文件」方式发送，不能用「图片」方式**，否则会被压缩损坏。

### 接收方
1. 点顶部密钥条，把密钥粘进去。
2. 「接收」Tab → 选择收到的 `.sft`（选中后要先点「移除」才能换一个）。
3. 点底部 **解密并查看**。解密成功后页面会自动收起「选文件 / 密钥」，只留结果；想看回来点标题右边的「展开文件 / 密钥」。
4. 图片显示为九宫格；点开是全屏黑底，**单指左右滑切换、双指放大**；视频直接播放。

### 大文件
加密/解密时会显示块数、速度（MB/s）和**剩余时间**，不用猜是不是卡住了。


## 体积上限

| 合计大小 | 行为 |
| --- | --- |
| ≤ 100 MB | 直接处理 |
| 100 ~ 300 MB | 二次确认（建议用电脑） |
| > 300 MB | 拒绝，请先压缩或剪辑 |

分片处理，所以**发送端内存与文件大小无关**；上限主要受限于接收端手机浏览器的组装与播放能力。

## 已知限制

- **HEIC / HEIF 无法预览**：iPhone 默认拍摄格式，安卓与电脑的浏览器画不出来。发送前请把「设置 → 相机 → 格式」改为「兼容性最佳」，或先导出为 JPG。加密过程本身不受影响。
- **微信/QQ 内置浏览器**：下载与播放常有问题，请点右上角「···」→「在浏览器打开」。
- 接收端目前**只做预览，不提供下载/ZIP 导出**（按当前需求）。

## 部署（GitHub Pages）

把 `index.html` 与 `sft-core.js` 放在仓库根目录，Settings → Pages → Source 选 `main` / `root` 即可。
页面必须通过 **https** 访问（GitHub Pages 默认就是），因为浏览器只在安全上下文里提供 WebCrypto。

## 自检

- 页面自检：打开 `https://<你的域名>/?selftest=1`，会在页面上逐条打印 PASS/FAIL。换手机、换浏览器后建议先跑一次。
- 核心自测（Node 18+）：`node dev/selftest.mjs`（26 项：往返、篡改、截断、错密钥、图集顺序）
- 界面端到端：`node dev/ui-e2e.mjs`（60 项：主题切换、Tab、选中锁定/移除、自动折叠、加密解密全流程、看图手势、错误分支）
- 静态检查：`node dev/check-html.mjs`（内联脚本语法、引用、id 唯一性、样式类）
